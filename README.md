# Cocos Creator Exporter

Export Figma designs directly to Cocos Creator format with full support for UI components, layouts, and effects.

## Features

- **Complete UI Export**: Exports frames, components, text, images, and vector shapes
- **Layout Preservation**: Maintains Widget layouts, constraints, and responsive behaviors
- **Effect Support**: Preserves shadows, strokes, fills, and blend modes
- **Text Formatting**: Keeps font styles, colors, and text effects
- **Asset Management**: Automatically handles image exports and sprite references
- **One-Click Export**: Simple interface for exporting selected frames or entire pages

## How to Use

1. Select the frame or component you want to export
2. Run the plugin from Plugins menu
3. Click "导出选中的图层" (Export Selected) or "导出当前页面" (Export Current Page)
4. Import the generated JSON file into Cocos Creator using the companion importer extension

## Requirements

- Figma Desktop App or Browser
- Cocos Creator 3.x with figma-cocos-importer extension installed

## Installation

Install from the Figma Community or:
1. Download the plugin files
2. In Figma: Plugins → Development → Import plugin from manifest
3. Select the manifest.json file
